# Ring Out 🥊🔥

A fast-paced, skill-based 3D Cyber Brawler built with React 19, Three.js, TypeScript, and Web Audio API.

## 🌟 Game Highlights
- **Dynamic Shrinking Arena**: Circular battle platform that progressively shrinks down to zero over 3 minutes.
- **Physics-Driven Combat**: Dash attacks, momentum rebounds, edge braking, and ring-out fall gravity.
- **Third-Person Follow Camera**: Over-the-shoulder action view with camera angle toggles (Third Person, Isometric Overview, Close Action).
- **Dual Controls**:
  - **Desktop**: WASD / Arrow keys for directional steering, Spacebar for Dash.
  - **Mobile**: Touch virtual joystick on the left thumb, tactile glowing Dash button on the right thumb.
- **Procedural Audio**: Zero-asset Web Audio API retro brawler sound effects (bump impacts, dash whooshes, defeat down-pit falls, victory fanfare).
- **Export Ready**: Capacitor ready for 1-click Android APK bundling.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
